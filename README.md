# FlowMat

This project tracks materials in an ERP workflow.

# Local Infra

Run local Redis and PostgreSQL:

```bash
docker compose -f flowmat_backend/compose.yaml up -d
```

Included health checks:
- Redis
- PostgreSQL

# Backend Ops

Actuator endpoints:
- `/api/actuator/health`
- `/api/actuator/health/liveness`
- `/api/actuator/health/readiness`
- `/api/actuator/info`
- `/api/actuator/prometheus`

Required production environment variables:
- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`
- `REDIS_HOST`
- `REDIS_PORT`
- `MAIL_HOST`
- `MAIL_PORT`
- `MAIL_USERNAME`
- `MAIL_PASSWORD`
- `JWT_SECRET`
- `FRONTEND_URL`
- `APP_OAUTH2_REDIRECT_URI`
- `APP_CORS_ALLOWED_ORIGINS`

Request tracing:
- incoming `X-Request-Id` is preserved
- missing `X-Request-Id` is generated by the backend
- log lines include `requestId`, `userId`, `projectId`, `workflowId`, `runId`

Rate-limited endpoints:
- `/api/auth/login`
- `/api/auth/refresh`
- `/api/auth/email/send-code`
- `/api/auth/reset-password/request`
- `/api/auth/reset-password/verify`
- `/api/auth/reset-password/confirm`
- `/api/auth/face/match`
- `/api/auth/face/select`
- `/api/auth/face/login`
