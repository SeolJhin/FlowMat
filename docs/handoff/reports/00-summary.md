## 사람 결정이 필요한 것

1. **D4 긴급:** 기존 dev/운영 DB의 V2·V4·V5 체크섬 해결 방식과 DB별 적용 승인. 기존 dev DB 기동 차단이 계속된다.
2. **D1·D3:** 협업 충돌 모델과 권한 매트릭스 확정.
3. **D2:** 계약서 `[구현 결정]` 승인.
4. **D5·D6:** STOMP 보안 독립 검토와 다중 사용자·부하·접근성 실사용 검증.

## 다른 담당에게 넘길 것

- **재고 프론트 담당:** `/inventories` 생성 타입에 실제 전송 중인 `lotId` 선언 추가.
- **BOM·LOT E2E 담당:** 로그인 성공 대기 조건 수정 후 CI와 로컬에서 재실행.
- **DB 운영 담당:** G와 C6에 따라 백업·사전 데이터 조회·제약 검증을 사람 승인 아래 수행.
- **협업 담당:** 첫 문서 동시 생성과 DB commit 이후 Redis 장애 처리 정책 설계.

커밋·푸시·브랜치 작업은 하지 않았다. 기존 마이그레이션과 다른 작업자 소유 파일도 수정하지 않았다. 새로 띄운 일회용 DB·백엔드는 종료했다.
