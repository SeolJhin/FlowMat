# E. 로컬 개발 환경

**한 줄 결론:** Compose용 예시 환경 파일과 백엔드 환경변수 적용 절차를 문서화했다.

## 한 것 / 못 한 것

- `flowmat_backend/.env.example`에 Compose와 `bootRun`의 환경변수 사용 차이, 비밀번호 일치, JWT 길이를 설명했다.
- `docs/local-development.md`에 설치, 새 DB 실행, 백엔드·프론트 시작, 데모 로그인, 오류 대응을 적었다. 별도 기동 스크립트는 선택 사항이라 만들지 않았다.
- `application*.yml`, `compose.yaml` 구조는 수정하지 않았다.

## 사람 결정이 필요한 것

- 기존 개발 DB를 어떻게 복구할지는 G 보고서의 선택이 필요하다.

## 다른 담당에게 넘길 것

- **운영/개발 환경 담당:** 실제 비밀값은 개인 `.env` 또는 비밀 관리 서비스에 넣고 저장소에 올리지 않는다.
