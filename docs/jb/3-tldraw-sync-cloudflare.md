# tldraw/tldraw-sync-cloudflare

- **주소**: https://github.com/tldraw/tldraw-sync-cloudflare
- **인기도**: 약 128 Star (템플릿 저장소)
- **라이선스**: MIT (이 저장소 자체는 MIT지만, tldraw SDK 본체는 위 tldraw 라이선스를 따름)
- **주요 언어**: TypeScript

## 한 줄 정의
> tldraw 캔버스에 **실시간 협업(멀티플레이어) 기능을 붙이기 위한 서버 템플릿**.

## 구조
- **Cloudflare Workers**: 서버 요청을 처리하는 경량 서버리스 환경.
- **Durable Object**: 방(캔버스 하나)마다 하나씩 만들어지는 미니 서버 인스턴스. 같은 방에 접속한 사용자들의 요청이 전부 이 하나의 인스턴스로 모여서, "누가 먼저 편집했는지" 충돌 없이 정리됩니다.
- **WebSocket**: 서버와 클라이언트가 실시간으로 양방향 통신하는 연결 방식. 편집 내용이 즉시 다른 사용자 화면에 반영되도록 씁니다.
- **R2**: Cloudflare의 이미지/영상 저장소.

## 언제 필요한가
tldraw 기반 캔버스에서 **여러 사용자가 동시에 같은 화면을 실시간으로 편집**해야 할 때 쓰는 백엔드 예제입니다. tldraw SDK 자체에 종속적이라, xyflow나 다른 라이브러리를 쓰는 경우엔 이 저장소를 그대로 재사용할 수 없습니다.

## FlowMat 연관성
FlowMat 문서에는 "협업 편집은 MVP 범위에 포함하지 않는다"는 항목이 명시돼 있어, 현재 시점에서는 이 저장소가 필요하지 않습니다. 추후 여러 명이 동시에 워크플로우를 편집하는 기능을 넣게 된다면, tldraw 대신 xyflow + Yjs 조합으로 비슷한 역할을 구현할 수 있습니다.
