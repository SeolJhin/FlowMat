# 작업자 달력

상태: **구현(2026-10-13, 세션 1 리드, §2 2du) — 로컬 격리 검증만.** 사용자 결정(2026-10-13, "Worker calendar"): 작업자는 프로젝트 구성원이고, 각자 주간 교대와 쉬는 날이 있다. 출처: [벤치마크](../reference/benchmarks/FlowMat_GitHub_Benchmark_2026-09-24.md) FM-PLAN-003 Calendar("작업자 교대"). 새 마이그레이션 **V80**(개발 DB 미적용). 같은 날 2dv(V81)에서 작업지시에 필요한 사람(crew)을 적고, 준비 점검·계획 제안이 그 사람들의 시간을 본다(WC11–WC16). 2dw(2026-10-14, 사용자 결정 "Worker load", 마이그레이션 없음)는 작업자 부하표와 같은 때 겹치는 인력 경고다(WC17–WC23). 2dx(같은 날, 사용자 결정 "Crew-aware plan dates", 마이그레이션 없음)부터 계획 제안이 인력의 교대와 다른 작업지시도 따른다(WC24–WC28). 2dy(같은 날, 사용자 결정 "Worker day overrides", **V82**, 개발 DB 미적용)는 날짜별 교대다(WC29–WC35). 2dz(같은 날, 사용자 결정 "Part-time crew", **V83**, 개발 DB 미적용)는 인력마다 몫(%)이다(WC36–WC40).

## 왜 필요한가

설비 달력([설비 달력](equipment-schedule.md))은 설비가 언제 도는지 알지만, 사람이 언제 일하는지는 몰랐다. 작업지시의 계획 기간에 맡을 사람이 쉬는 날이면 설비만 보고는 알 수 없다.
