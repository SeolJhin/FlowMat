# FlowMat 현재 기능 기준선

확인일: 2026-10-03. 코드 기준 커밋 `45f5df0`(마이그레이션 V1–V41)과 커밋 전 작업 트리(V42–V51, 2026-10-03). 직전 커밋 `6c383d4`에서 GitHub Actions 4개(백엔드 테스트·빌드, 프런트 테스트·린트, 백엔드 포함 브라우저 E2E, 의존성 보안 검사)가 통과했다. `45f5df0`의 추가분(다단계 역전개·원가 누적·프로젝트 휴일·결함 수정 4건)은 커밋 전 로컬에서 백엔드 959건·프런트 364건·실 API E2E 26건이 통과했고, 이 커밋의 CI 결과는 이 문서에서 확인하지 않았다. 커밋 전 작업 트리(V42–V51과 같은 날의 기능 추가)는 2026-10-03 로컬에서 마지막으로 전체를 다시 돌렸다(V51 설비 상태 이력과 모든 단계 반제품 초안 작업지시까지): 백엔드 987건과 커버리지 기준, 프런트 409건·린트·타입 검사·빌드, 브라우저 E2E 34건(실 API 포함, 가짜 API `sub-assembly-order`·`byproduct-finish`·`multi-level-bom` 포함). 아키텍처 결정은 [결정 인계](../architecture/decision-handoff.md). 이 문서는 특정 배포 버전의 보증서가 아니다. 기능 상태를 바꿀 때는 근거 코드와 검증 결과를 함께 갱신한다.

상태: **IMPLEMENTED**는 코드와 대응 경로가 있음, **PARTIAL**은 일부 흐름만 있음, **PLANNED**는 제안만 있음. 이 표의 상태는 설계 범위 기준이며 운영 환경 검증을 뜻하지 않는다.
